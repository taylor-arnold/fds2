4. The block below is given. It sorts `klog` by person and press time, then
adds three columns. `press` and `release` turn `t0` and `t1` into `Datetime`
values by casting the milliseconds to an integer and then to
`pl.Datetime("ms")`. That reads them as a Unix timestamp, so every session's
clock starts at 1970-01-01 00:00:00 instead of a real date; only the clock
time matters, and it means time elapsed since recording began. `gap` is a
`Duration`: the time between the release of the previous key and the press
of this one, computed within each person with `.over(c.id)`. The first key
of each session has no previous key, so its `gap` is `null`. Run the block
and look at the new columns.

```{python}
#| tags: [noclear]
klog = (
    klog
    .sort(c.id, c.t0)
    .with_columns(
        press = c.t0.cast(pl.Int64).cast(pl.Datetime("ms")),
        release = c.t1.cast(pl.Int64).cast(pl.Datetime("ms"))
    )
    .with_columns(
        gap = c.press - c.release.shift(1).over(c.id)
    )
)
klog
```
