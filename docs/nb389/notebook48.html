6. The block below is given. It loads the SigLIP model and builds a text embedding of
the phrase "a photo of a ..." for each of the ten breeds. The result is saved as
`breed_embed`, with one row per breed. Run it and look at the table.

```{python}
#| tags: [noclear]
siglip = SigLIPEmbedder()

breed_embed = (
    woof
    .select(text = c.label.unique())
    .sort(c.text)
    .with_columns(
        prompt = pl.lit("a photo of a ") + c.text.str.replace_all("_", " ")
    )
    .with_columns(
        siglip_txt = c.prompt.map_elements(
            siglip.embed_text, return_dtype=pl.List(pl.Float32)
        )
    )
)
breed_embed
```

7. Filter `breed_embed` to the row where `text` is `"golden_retriever"`, and
cross-join `woof` to it with `.join(..., how="cross")`. Add a column
`sim_score = dot_product(c.siglip, c.siglip_txt)`, sort from the highest to the
lowest score, keep the first 8 rows, and show them with `DSImage.plot_image_grid`
labeled by `label`.

```{python}
(
    woof
    .join(breed_embed.filter(c.text == "golden_retriever"), how="cross")
    .with_columns(
        sim_score = dot_product(c.siglip, c.siglip_txt)
    )
    .sort(c.sim_score, descending=True)
    .head(8)
    .pipe(DSImage.plot_image_grid, label_name="label", ncol=4)
)
```

All eight photographs are golden retrievers. The model was never given any of our
labels; it learned from images and captions that this look goes with those words.

8. Now classify every photograph. Cross-join `woof` to all of `breed_embed`, compute
`sim_score` as before, and sort from highest to lowest. Keep the best breed for each
photograph with `.group_by(c.filepath).head(1)`, and compute the share of photographs
where the true `label` matches the predicted breed `text`.

```{python}
(
    woof
    .join(breed_embed, how="cross")
    .with_columns(
        sim_score = dot_product(c.siglip, c.siglip_txt)
    )
    .sort(c.sim_score, descending=True)
    .group_by(c.filepath)
    .head(1)
    .select(class_rate = (c.label == c.text).mean())
)
```

The classifier gets 91.6% of the photographs right, without any training on our
data.
