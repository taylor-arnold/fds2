### Questions

Four tables this time. `rva` has one row for each of the 24,808 commercial flights
that left Richmond International Airport in 2019, with the date, the scheduled and
actual times, the delays in minutes, the `carrier` code of the airline, and the
`dest` code of the airport it flew to.

The other three tables describe things that the flights point to. `airline` has one
row per airline, with the two-letter `carrier` code and the airline's `name`.
`airport` has one row per airport, with its three-letter `faa` code, `name`, `lat`,
and `lon`. `weather` has one row per hour of the year, with `year`, `month`, `day`,
`hour`, the `wind_speed`, and the visibility `visib` in miles.

Unless a question says otherwise, just print the result of each block; do not save it
to a variable.

1. Start with one table. Count the number of flights for each `carrier` and sort from
the most flights to the fewest.

```{python}
(
    rva
    .group_by(c.carrier)
    .agg(n = pl.len())
    .sort(c.n, descending=True)
)
```

There are 14 carriers. The codes are hard to read: who are `OO` and `9E`?

2. Join `airline` onto `rva` using the key `carrier`, and select the columns `carrier`,
`name`, and `dest`.

```{python}
(
    rva
    .join(airline, on=c.carrier)
    .select(c.carrier, c.name, c.dest)
)
```

The result still has 24,808 rows, one per flight. Each flight now carries the full
name of its airline.

3. Take the code from the previous question, but instead of selecting columns, group
by `name` and compute the number of flights and the mean departure delay
(`dep_delay`). Sort from the largest mean delay to the smallest.

```{python}
(
    rva
    .join(airline, on=c.carrier)
    .group_by(c.name)
    .agg(
        n = pl.len(),
        mean_dep_delay = c.dep_delay.mean()
    )
    .sort(c.mean_dep_delay, descending=True)
)
```

ExpressJet is the worst at 23 minutes late on average. Delta is the best at under two
minutes.

4. Now the destinations. Count the number of flights to each `dest`, then join
`airport` to get the airport names. The key has a different name in the two tables,
`dest` in the flights and `faa` in the airports, so use `left_on` and `right_on`. Sort
by the number of flights.

```{python}
(
    rva
    .group_by(c.dest)
    .agg(n = pl.len())
    .join(airport, left_on=c.dest, right_on=c.faa)
    .sort(c.n, descending=True)
)
```

Richmond flies to 22 airports. Atlanta is by far the most common destination.

5. Take the code from the previous question and draw a map: longitude on the x-axis,
latitude on the y-axis, and the size of each point given by the number of flights.

```{python}
(
    rva
    .group_by(c.dest)
    .agg(n = pl.len())
    .join(airport, left_on=c.dest, right_on=c.faa)
    .ggplot(aes(c.lon, c.lat))
    .geom_point(aes(size=c.n))
)
```

The flights table had no coordinates in it. The join brought them in from `airport`.

6. Last one. The weather is recorded once per hour, so the key that connects a
flight to the weather is four columns: `year`, `month`, `day`, and `hour`. Join
`weather` onto `rva` using all four columns, and select the columns `month`, `day`,
`hour`, `dep_delay`, and `wind_speed`.

```{python}
(
    rva
    .join(weather, on=[c.year, c.month, c.day, c.hour])
    .select(c.month, c.day, c.hour, c.dep_delay, c.wind_speed)
)
```

This is the same kind of key that you will use in your project to join your `hours`
table to the weather: a date and an hour, together.
